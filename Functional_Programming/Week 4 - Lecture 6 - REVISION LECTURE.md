## Ad-hoc polymorphism
Similar to Java interfaces
overloading in java is a form of ad-hoc polymorphism
```
public float add(float f1, float f2) {...}
public int add(int i1, int i2) {...}
```

instance declaration:
- Specify the implementations of each function explicitly
deriving clause:
- Implement the type-class using default behaviour
